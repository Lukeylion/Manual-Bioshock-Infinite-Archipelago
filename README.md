# Manual-Bioshock-Infinite-Archipelago
A Bioshock Infinite archipelago thats manual so no mod
(Go to the actual readme file then code to have it in proper formating)
How to set-up
1. Download the archipelago launcher https://github.com/ArchipelagoMW/Archipelago/releases/tag/0.6.7 (you may also need https://github.com/ManualForArchipelago/Manual/releases)
2. Download the latest release of the Bioshock Infinite manual apworld
3. Host a server through archipelago website or from the launcher
4. In the archipelago client run the manual client
5. up the top choose the game
6. connect to your server
7. done

How to use manual client: At the top theres a button called manual click on that then you should see a bunch of categories on the right these are you checks and on the left are the items you have unlocked

NOTE: This is a manual so you have to select when you get checks.
When you get a vigor in game you arent allowed to use it until you unlock it in the archipelago
This is still WORK IN PROGRESS currently working on can be found at the bottom
